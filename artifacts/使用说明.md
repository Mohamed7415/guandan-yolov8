# 《天天爱掼蛋》牌面识别模型

正式模型：`card_model.onnx`（YOLOv8n，54 类，FP32，opset 12）。类别索引见 `classes.txt`；完整参数和指标见 `model_info.json`。

输入 RGB float32 `[1,3,640,640]`，原图保持比例缩放、用 114 填边、除以 255。输出 `[1,58,8400]`：4 个输入像素单位的 cx/cy/w/h，以及 54 类分数，无额外 objectness，无内置 NMS。建议起始置信度 0.25，类别感知 NMS IoU 0.45，再将框还原到原图坐标。

项目内识别：

```sh
.venv/bin/python scripts/infer_onnx.py /绝对路径/游戏截图.png --output reports/my_predictions
```

如使用独立模型包，在解压目录安装 `requirements-inference.txt`，然后运行：

```sh
python infer_onnx.py /绝对路径/游戏截图.png --model card_model.onnx --output predictions
```

会输出识别 JSON 和画框预览。模型包中的 PyTorch 权重仅用于继续训练，无需为 ONNX 推理加载。

2000 张真实截图，54 类，按整局分开训练/验证/测试。208 张测试图在原图复核修订标签后，mAP50 99.47%，mAP50–95 99.35%。置信度 0.25 时仍有 24 个额外框，190/208 张整图完全匹配。原冻结测试 mAP50 为 99.15%；修订了 10 个花色误标及 13 个漏框，权重与阈值未改动。详细审计见项目 `reports/FULL_2000_REPORT.md`。

主要适用当前小程序主题和原生 1620×1000 截图；独立扇形手牌、其他主题/分辨率未单独验证。标注由助手复核，尚无独立人工二审。
